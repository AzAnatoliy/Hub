# 🤝 Руководство по участию

Спасибо за интерес к проекту Media Hub! Мы приветствуем любой вклад в развитие проекта.

## 📋 Как внести вклад

### Сообщить о баге

1. Проверьте существующие [issues](https://github.com/YOUR_USERNAME/media-hub/issues)
2. Если баг не описан, создайте новый issue
3. Укажите:
   - Версию системы
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Логи (если есть)

### Предложить улучшение

1. Создайте issue с меткой `enhancement`
2. Опишите идею подробно
3. Объясните, какую проблему решает предложение

### Отправить Pull Request

1. Форкните репозиторий
2. Создайте ветку для вашей функции:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. Внесите изменения
4. Протестируйте локально
5. Закоммитьте изменения:
   ```bash
   git commit -m 'Add amazing feature'
   ```
6. Отправьте в ветку:
   ```bash
   git push origin feature/amazing-feature
   ```
7. Откройте Pull Request

## 💻 Разработка

### Требования

- Node.js 20.x
- npm 10.x
- Docker (для тестирования контейнеров)

### Локальная разработка

```bash
# Клонирование
git clone https://github.com/YOUR_USERNAME/media-hub.git
cd media-hub

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка
npm run build

# Проверка типов
npm run typecheck
```

### Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Dashboard.tsx    # Главная страница
│   ├── VideoSection.tsx # Видео
│   ├── MusicSection.tsx # Музыка
│   └── ...
├── App.tsx             # Главный компонент
└── main.tsx            # Точка входа
```

### Стиль кода

- Используйте TypeScript
- Следуйте ESLint правилам
- Пишите комментарии на русском языке
- Используйте осмысленные имена переменных

### Тестирование

Перед отправкой PR убедитесь, что:
- [ ] Код компилируется без ошибок
- [ ] Все существующие функции работают
- [ ] Добавлены новые тесты (если применимо)
- [ ] Документация обновлена

## 📝 Коммиты

Используйте осмысленные сообщения коммитов:

```
feat: добавлена поддержка нового формата
fix: исправлена ошибка воспроизведения
docs: обновлена документация
style: форматирование кода
refactor: рефакторинг компонента
test: добавлены тесты
chore: обновление зависимостей
```

## 🎨 Дизайн

При добавлении новых компонентов:
- Следуйте существующему стилю
- Используйте Tailwind CSS
- Обеспечьте адаптивность
- Поддержите темную тему
