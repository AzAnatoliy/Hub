# 🤖 Hermes AI - Голосовой ассистент

Hermes AI — это интеллектуальный голосовой ассистент для Media Hub, обеспечивающий управление медиа, умным домом и системой через голосовые команды.

## 🎯 Возможности

### 🎬 Управление медиа
- Поиск и воспроизведение фильмов, сериалов, музыки
- Управление плейлистами
- Переключение треков
- Регулировка громкости

### 🏠 Умный дом
- Управление освещением
- Контроль климата
- Управление устройствами
- Создание сценариев

### 📊 Системные команды
- Статус системы
- Мониторинг ресурсов
- Управление сервисами
- Диагностика проблем

### 🗣️ Голосовое управление
- Wake word: "Привет, Гермес"
- Распознавание речи (Whisper)
- Естественный язык
- Русский язык

## 🚀 Установка

```bash
# Запустите скрипт установки
chmod +x scripts/install-hermes.sh
sudo ./scripts/install-hermes.sh
```

## ⚙️ Настройка

### 1. Отредактируйте конфигурацию

```bash
sudo nano /etc/hermes-ai/config.yaml
```

### 2. Настройте Home Assistant токен

1. Откройте Home Assistant: http://localhost:8123
2. Перейдите в Профиль → Long-Lived Access Tokens
3. Создайте новый токен
4. Скопируйте токен в конфиг:

```yaml
home_assistant:
  enabled: true
  url: "http://localhost:8123"
  token: "YOUR_TOKEN_HERE"
```

### 3. Выберите модель Whisper

В зависимости от производительности системы:

```yaml
# Для слабых систем (i3, 8GB RAM)
whisper_model: "tiny"

# Для средних систем (рекомендуется)
whisper_model: "base"

# Для мощных систем (лучшее качество)
whisper_model: "small"
```

### 4. Перезапустите сервис

```bash
sudo systemctl restart hermes-ai
```

1. Скажите wake word: **"Привет, Гермес"**

3. Скажите команду

## 🔌 API

Hermes AI предоставляет REST API:

### Статус
```bash
curl http://localhost:5000/api/status
```

### Текстовая команда
```bash
curl -X POST http://localhost:5000/api/command \
  -H "Content-Type: application/json" \
  -d '{"text": "включи музыку"}'
```

### Управление прослушиванием
```bash
# Начать слушать
curl -X POST http://localhost:5000/api/listen \
  -H "Content-Type: application/json" \
  -d '{"action": "start"}'

# Остановить
curl -X POST http://localhost:5000/api/listen \
  -H "Content-Type: application/json" \
  -d '{"action": "stop"}'
```

## 📊 Требования к системе

### Минимальные
- CPU: 2 ядра
- RAM: 2 ГБ (для модели tiny)
- Микрофон: USB или встроенный
- Python: 3.8+

### Рекомендуемые
- CPU: 4 ядра
- RAM: 4 ГБ (для модели base)
- Микрофон: USB с шумоподавлением
- GPU: NVIDIA с CUDA (опционально, для ускорения)

## 🐛 Решение проблем

### Микрофон не работает

```bash
# Проверьте устройства
arecord -l

# Проверьте права
sudo usermod -aG audio $USER

# Перезагрузитесь
sudo reboot
```

### Высокая задержка распознавания

1. Используйте модель `tiny` или `base`
2. Убедитесь, что система не перегружена
3. Проверьте логи: `sudo journalctl -u hermes-ai -f`

### Низкая точность распознавания

1. Используйте модель `small` или `medium`
2. Улучшите качество микрофона
3. Говорите четко и медленно
4. Уменьшите фоновый шум

### Wake word не срабатывает

1. Проверьте конфигурацию:
   ```yaml
   voice_wake_word: "привет гермес"
   ```
2. Говорите четко
3. Убедитесь, что микрофон работает
4. Проверьте логи

## 🔒 Безопасность

- API слушает на всех интерфейсах (0.0.0.0)
- Для production настройте firewall:
  ```bash
  sudo ufw allow from 192.168.1.0/24 to any port 5000
  ```
- Используйте HTTPS для удаленного доступа
- Регулярно обновляйте зависимости

## 📈 Производительность

### Оптимизация

1. **Модель Whisper**: Используйте `tiny` для слабых систем
2. **Длительность записи**: Уменьшите до 3 секунд
3. **VAD (Voice Activity Detection)**: Добавьте для экономии ресурсов
4. **Кэширование**: Кэшируйте частые команды
